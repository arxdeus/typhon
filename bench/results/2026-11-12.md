## Notes

* Correctness: Codon and Typhon match each other everywhere. chaos: Codon, Typhon and typed Cython all write the same PPM, which differs from CPython's (hash d1d0... vs f53f...). The image size is the same and pixel sums are within 0.03%, so this is float rounding/FMA in the spline math, not a logic error. mandelbrot typed Cython: pixel sum 18607990 vs 18607941 (a few boundary pixels, FMA in its hand-written complex loop at N=512). Everything else matches at the tiny check args and at the measurement args.
* Typhon outlier: on float, Typhon is 4.9x slower than Codon (10M small-object allocations plus sin/cos/sqrt). This is a real Typhon codegen/runtime regression worth investigating. binary_trees (allocation-heavy) is 1.29x. All other benchmarks are within ±4%. Excluding float, the Typhon/Codon runtime geomean is about 1.02.
* Load average was low during this run (1-min 1.5-2.6). The 15-min average fell from 7.9 to 4.0. Per-backend run spread is <3% except CPython fannkuch (6%).
